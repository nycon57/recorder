# Support Quality Assurance Framework

**Owner:** Priya Rangan
**Review Cycle:** Quarterly

## Scoring Dimensions

Each ticket review scores on five dimensions (1–5 scale each, max 25 points):

| Dimension | Weight | Criteria |
|-----------|--------|---------|
| Accuracy | 5 | Is the information correct and complete? |
| Tone | 5 | Empathetic, professional, brand-aligned? |
| Efficiency | 5 | Was the issue resolved in minimum exchanges? |
| Process adherence | 5 | Did the agent follow the correct workflow? |
| Documentation | 5 | Were internal notes, tags, and fields completed? |

## Scoring Thresholds

| Score | Rating | Action |
|-------|--------|--------|
| 23–25 | Exceptional | Feature in team recognition |
| 19–22 | Meets standards | No action |
| 14–18 | Developing | Coaching session + follow-up review |
| < 14 | Needs improvement | Performance plan |

## QA Cadence

- Each agent: 5 tickets reviewed per month (random sample)
- Focus reviews: triggered by bad CSAT (rating 1 or 2)
- Calibration: QA team reviews same ticket independently monthly to check for scoring drift

## CSAT Correlation Targets

- Monthly CSAT ≥ 92%
- First contact resolution ≥ 78%
- Average QA score ≥ 20/25

## Agent Self-Review

Agents review their own bad CSAT responses before the monthly QA session. Internal note added to each bad-CSAT ticket explaining what the agent would do differently.
