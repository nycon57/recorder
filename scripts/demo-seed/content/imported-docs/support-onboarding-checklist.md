# Support Agent Onboarding Checklist

**Complete within first 5 business days.**

## Day 1 — Account Access

- [ ] Zendesk account created, role = Agent, group = Tier 1
- [ ] HubSpot access granted (Reporter role)
- [ ] Jira access granted (Reporter role, SUP project)
- [ ] Slack channels joined: #support-team, #support-billing, #support-handoffs, #engineering-escalations
- [ ] Zendesk: pin 4 views (My open, SLA breach risk, Waiting for customer, Tier 1 unassigned)
- [ ] Zendesk: apply 5 core macros from macro library
- [ ] Send test ticket to self and verify receipt

## Day 2 — Tools Deep Dive

- [ ] Zendesk Talk configured: routing group assignment, voicemail recorded, availability toggle tested
- [ ] Review SLA targets (see wiki: Zendesk SLA and Business Hours)
- [ ] Shadow senior agent on 5 live tickets
- [ ] Review tag allowlist and confirm understanding of automation-triggering tags

## Day 3 — Billing Flows

- [ ] Walk through partial refund flow in HubSpot with mentor (do not process real refunds yet)
- [ ] Understand approval thresholds (< $500 self-authorized, > $500 dual approval)
- [ ] Review HubSpot deal refund properties

## Day 4 — Engineering Escalations

- [ ] Walk through Jira bug creation from Zendesk ticket
- [ ] Understand severity labels and when to use each
- [ ] Attend weekly support-engineering sync (Tuesdays 10am)

## Day 5 — Certification

- [ ] Complete 10 tickets independently (reviewed by mentor)
- [ ] First CSAT target: 90% positive
- [ ] Sign off on: SLA policy, refund authority matrix, escalation protocol
