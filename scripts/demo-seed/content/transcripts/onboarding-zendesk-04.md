Setting up Zendesk macros for a new tier-1 agent. We have 18 macros in the system. For a new hire, start them with five: Initial greeting, Request more info, Issue escalated to tier 2, Refund initiated, and Ticket resolved closing. Walk them through how to apply a macro — there's a button in the ticket compose toolbar, not in settings. Common mistake: agents try to find macros in their profile settings and can't. They're ticket-level, not account-level. Each macro can set the ticket status, add a comment, add tags, and reassign. The escalation macro we have automatically adds the tag needs-tier-2 and reassigns to the Tier 2 group — agents don't need to remember to do that manually. One thing I always tell new hires: macros are a starting point, not a complete response. Personalize the customer's name and reference their specific issue. A template that reads like a template destroys customer trust faster than a slow reply does.
