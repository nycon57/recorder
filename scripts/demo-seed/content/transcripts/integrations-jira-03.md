Setting up the Jira-Zendesk integration for a new team member. Go to Zendesk Admin Center, then Apps and integrations, then Jira. If the integration is already configured at the org level, you just need to make sure it's visible in the agent's sidebar. Open the app settings and check Allow all agents. If only specific agents are listed, add the new hire. The Jira panel in the ticket sidebar will appear automatically on next login. For the agent to create Jira issues, they need a Jira account. We use our company SSO for Jira — they should already have one if they've done IT onboarding. If the Jira panel shows Authentication required, have them click it and log in with their SSO. Permission scope: tier-1 agents get Reporter access in Jira by default. They can create issues and comment but cannot transition issue status. Status transitions are owned by the assigned engineering team lead. Agents sometimes get confused when they can't move a Jira issue to In Progress — remind them that's intentional. Our workflow is you create it, engineering owns it from there.
