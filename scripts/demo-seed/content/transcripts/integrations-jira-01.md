When a tier-1 ticket escalates to engineering, we create a Jira bug from inside Zendesk — not by flipping tabs. In the ticket sidebar, there's a Jira panel. Click Create issue, pick the SUP project, issue type Bug, and priority matches the ticket priority. Summary should copy the ticket subject verbatim; description gets the customer's reproduction steps plus what you already tried. Critical: tag the issue with customer-impacting — engineering filters their triage board on that label. Link the Zendesk ticket URL in the Jira description; our Rovo integration auto-links backwards too, so once it's in Jira you'll see a Jira pill on the Zendesk ticket. Any status change on the Jira side fires a comment on the Zendesk ticket — do not disable those notifications, customers need to see the handoff. One gotcha: if the Jira project is missing the customer-impacting label in its scheme, the field shows blank. Ping Priya to get it added; she's admin on both sides.
