Zendesk Talk setup for voice support. Every new agent who's on the voice rotation needs three things configured before their first call. First, Talk number assignment — go to Channels, then Talk, then Numbers, and add the agent to the routing group. Without this they simply will not receive calls. Second, voicemail — agents need to record their own greeting. The default greeting is the company name only, which is fine for the main line but not for callbacks. Third, availability toggle — this is critical. When an agent is available in Talk, they're in the queue. If they forget to set themselves unavailable during lunch or a meeting, calls route to them and go unanswered. We've had three complaints this quarter about unanswered calls from agents who forgot to toggle off. I'm going to add a reminder to the end-of-shift checklist. The other thing to cover: wrap-up time. After a call ends, Talk gives agents 60 seconds of wrap-up time to add notes before they're back in the queue. Do not skip this. Notes from the call are critical for continuity if the customer calls back.
